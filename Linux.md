# Introduction to Linux

Linux is a free, open-source, Unix-like operating system kernel created by Linus Torvalds in 1991, powering everything from servers and supercomputers to Android devices and desktop distributions such as Ubuntu, Debian, Fedora, and Arch Linux.

---

## What Linux Is
* **Definition:** Linux is a family of open-source operating systems built around the Linux kernel. *(Source: Wikipedia)*
* **Initial Release:** First released on 17 September 1991 by Linus Torvalds. *(Source: Wikipedia)*
* **GNU Integration:** Often combined with GNU tools, forming GNU/Linux systems. *(Source: Encyclopedia Britannica)*
* **Scope of Use:** Used in servers, desktops, embedded systems, and all Android devices. *(Source: toolcalclab.com)*

---

## Key Features
* **Open Source:** Free to use, modify, and distribute.
* **Security:** Strong permission model, SELinux, and frequent updates.
* **Stability:** Rarely crashes; ideal for enterprise servers.
* **Customizability:** Offers many desktop environments, kernels, and system configurations.
* **Community Support:** Large global community and thousands of open-source tools.

## Linux Architecture
1. **Kernel:** Manages hardware, processes, and memory.
2. **System Libraries:** Provide essential functions for application software.
3. **Shell:** Command-line interface used for executing system commands.
4. **System Utilities:** Specialized tools used for overall system management.
5. **Hardware Layer:** Comprises CPU, RAM, storage, and I/O devices.

---

## Common Use Cases
* **Servers:** Powers the vast majority of web servers and cloud infrastructures globally.
* **Supercomputers:** 100% of the world's top 500 supercomputers run on Linux.
* **Mobile Operating Systems:** Android relies on a modified version of the Linux kernel.
* **Embedded Systems:** Used in network routers, IoT devices, smart TVs, and automotive technology.
* **Desktop Computing:** Provides customizable user experiences via environments like GNOME, KDE, and XFCE.

## Basic Linux Concepts

### File System
Hierarchical tree structure starting at the root directory (`/`).
* **Common Directories:**
  * `/home` – User home directories
  * `/etc` – Configuration files
  * `/usr` – User binaries and documentation
  * `/var` – Variable files like logs
  * `/bin` – Essential user command binaries
  * `/opt` – Optional add-on software packages

### Essential Commands
* `ls` – List directory contents
* `cd` – Change current directory
* `cp`, `mv`, `rm` – File operations (copy, move/rename, remove)
* `chmod`, `chown` – Modify permissions and file ownership
* `apt`, `dnf`, `pacman` – Package management commands

### Package Management
* Handles installation, updates, and removal of software.
* Varies by distribution:
  * **APT:** Debian / Ubuntu
  * **DNF:** Fedora / RedHat
  * **Pacman:** Arch Linux

### System Administration
* Involves managing users, system processes, networks, services, logs, and security policies.
* Shell scripting automates system operations and repetitive tasks.

## History Timeline
* **1969:** Unix is created at Bell Labs.
* **1983:** The GNU Project is launched by Richard Stallman.
* **1991:** Linus Torvalds releases the initial Linux kernel.
* **1993:** Debian and Slackware distributions emerge.
* **1994:** Linux kernel version 1.0 is officially released.
* **2008:** The Android operating system is released.
